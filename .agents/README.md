# NYshift design skills

This project includes the Playful Design Router and its 43 companion skills in `.agents/skills/`. Complete skill folders retain upstream references, scripts, templates and licenses. This is a pinned copy; see `upstream.json` for its source commit. Installation copied files only and ran no third-party scripts.

Open this repository as the project in Codex to discover repository skills. Local and cloud environments need a checkout containing these files. This does not install personal skills on a computer or add an account-wide plugin. Codex normally detects skill changes automatically; restart the session if they are missing.

Use `$playful-design-router` to choose a workflow, or mention a specific skill. Skills that require explicit invocation retain their upstream settings. The collection includes Benji Taylor's Stageshow; use the installed copy rather than installing another version with the same name.

The user's MapleStory material direction and this project's established conventions take precedence over generic styling defaults. Installing the collection does not change the website.

Sources and licenses: https://github.com/Playful-Design/router . Original author attributions and all license files supplied by the upstream collection are retained.
